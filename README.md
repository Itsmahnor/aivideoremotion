# AI Video Studio

An npm-workspaces monorepo for the API, web player, shared schemas, and Remotion compositions.

Run `npm install`, then use `npm run studio` for Remotion Studio or `npm run dev:web` for the browser player.

## Web app

`npm run dev:web` opens a five-step workflow: product details → video customization → script and storyboard review → generation → export. See `apps/web/README.md` for what works in the browser alone and `apps/web/INTEGRATION.md` for connecting real AI, voice-over and rendering services.
