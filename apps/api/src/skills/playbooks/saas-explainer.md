# Product overview playbook

- Open with the pain the audience feels (HookStatement), then reveal the product (ProductReveal) within the first 15 percent of the video.
- Show one or two real screens with ScreenshotShowcase. Each caption states one thing to notice, 12 words or fewer.
- Use FeatureSpotlight for at most three features, alternating layout left and right.
- Use StepFlow only if the product has a clear setup process.
- End with CTAEndCard, exactly once, as the last scene.
- Use only facts the user provided. Never invent numbers, customers or features.
